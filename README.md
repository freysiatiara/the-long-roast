## The line

> Muse Spark holds 200,000 tokens of context and still loses my name by turn three — a goldfish with a library card.

## How it works

`main.py` (Python standard library only) writes that single line to
`/output/entry.txt` with mode `0644`. No network, no dependencies, no
secrets — the whole entry is the one line above.
